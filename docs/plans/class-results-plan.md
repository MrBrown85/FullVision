# Class Results (2026-11-06)

## Context

Colin wants the gradebook's Class Average cell to answer "how did the class do on this piece, and who needs follow-up". The approved mockups are on the canvas at https://claude.ai/artifact/Jf854VZgF3BtCsofswRb3P (private): a hover card on the Class Average cell, a **View Class Results** item in the column-header menu, and a Class Results panel with one layout per scoring mode (rubric/competencies, Points, Complete/Incomplete, DIBELS). Everything lands in **one pull request and one merge** (Netlify credits are scarce; only merges to `main` deploy). Branch from `origin/main`, not from `feat/dashboard-cards` (unmerged, separate work).

Where to look while building: the canvas's artboards (`Main.dc.html` hover card, `Panel.dc.html` rubric panel with the Grading Style and Rubric Levels tweaks, `Points.dc.html`, `Complete.dc.html`, `Dibels.dc.html`, `Menu.dc.html`) hold the approved markup, spacing and wording; read them with the Artifact tool (`action: read`, `path: project/<name>`) rather than inventing a layout. Their colours are the gradebook's own soft palette (`teacher/gradebook.css` `.gb-grid` scope).

Two findings from exploring the code change the original plan:

1. **No migration.** "Other Classes" needs no new column. Assessments copied to other classes already share `copy_group`; `findCopies(cid, a)` in `teacher/assessment-copy.js:315` returns `[{cid, assessmentId, className}]` (server: `list_assessment_copies` RPC; Demo Mode: scans the loaded classes), and `loadClass(cid)` (`shared/data.js:1426`) brings another class's bundle, scores included, into the cache. The same-class Duplicate button (`dupeAssess`, `page-assignments.js:6478`) deliberately drops `copyGroup`; that is new work, not a linked copy, so it should not appear under Other Classes. The `duplicate_assessment` RPC is unused by the app. **Do not touch the database in this PR** — the CI drift check would otherwise block the PR until the migration is applied to prod.
2. **DIBELS accuracy is computable.** `getDibelsScore` returns `{orfWrc, orfErrors, …}` and `dibelsAccuracy(wrc, errors)` exists (`shared/constants.js:465`). Median accuracy is a helper, not a schema change; it hides when no student has errors entered.

Decisions already made by Colin (record both in `docs/DECISIONS.md`):

- **No designation-group statistics.** Never compare ELL or any BC designation against the class in a statistic. A designation shows only as a tag beside a student's name (Nov 5).
- **Class Results**: the hover card shows spread, median/range, completion; the panel adds the rubric/competency grid, student lists with actions, feedback count, observations, Other Classes, Earlier in <Category>; one layout per scoring mode; the panel sizes to its content; colour means proficiency level only; no grey explainer lines; no standard deviation; no email/messaging; no trend chart on rubric work beyond Earlier in <Category>.

Rules that hold throughout (CLAUDE.md): grade math only in `shared/calc.js`; every displayed level/grade through `formatLevel` / `formatLevelAs` / `levelWord` / `levelFigure` / `classColumnAverageText` (`tests/grade-format-guard.test.js` caps `.toFixed(1)` and `PROF_LABELS[` per file — new files get 0); every string into HTML through `esc` (`shared/html.js`); no new innerHTML site the audit can't prove (`npm run audit:html`; mark reviewed sinks with `// html-safe: <reason>`); Title Case labels, plain sentences; Demo Mode must show every feature; `npm run format:check` (Prettier) must pass.

## A. Grade math (`shared/calc.js`) — flag for Colin's review in the PR

All new helpers take `(cid, students, assessment)` where `students` is the gradebook's full roster (`_averageStudents` in page-gradebook, i.e. `sortStudents(getStudents(cid), 'lastName')`), and build on `columnCountedValue` / `COLUMN_STATUS_RULES` so Missing and Excused count exactly as the Class Average does (Letter class: NS = 0; Proficiency/Both: NS left out; EXC always out).

1. `classColumnSpread(cid, students, col)` → `{values: [{sid, value}], median, low, high, count}` for level columns, or `{…, earned/possible per value}` for points read as points. Sorted ascending. Reuse in `refreshLedgerSummary` (`page-assignments.js:6692`) is optional; at minimum the new panel and the ledger must agree, so write a test that compares them on the same seed. Move `_median` out of `comment-bank.js:2867` only if trivial; otherwise leave it.
2. `classColumnLevelCounts(cid, students, col)` → `{counts: {1,2,3,4}, ids: {1:[sid…],…}, scored}` from the rounded level of each counted value (`Math.round`, clamp 1–4; a Letter-class NS counts as level 1 only if `value` is 0 — follow `_percentLevel` for a % column: 0% → level 1). Used for the proficiency bar, the Below Proficient list (`ids[1] ∪ ids[2]`) and the hover card.
3. `classRubricGrid(cid, students, assessment)` → `{rows: [{id, name, counts, ids, avg}]}`, one row per criterion (`_assessmentRubric(cid, a).criteria`, in `displayOrder`), levels from `rubricCriterionLevel` (round, clamp 1–4; `null` = unscored, not counted), `avg` the mean level. Returns `null` with no rubric.
4. `classCompetencyGrid(cid, students, assessment)` → same shape, one row per competency in `rubricCompetencyRowKeys(cid, a)` (or `scoreTagIds` for competencies-only work), the mark from `competencyLevelFromCriteria` (rubric) or the student's tag entry (`scoreModValue`), rounded. Row `name` is the tag's code + name from the course's learning map (`getTagById`/sections — find the existing lookup used by `_showCodeTip`).
5. `classColumnStatusCounts(cid, students, assessment)` → `{scored, missing: [sid], excused: [sid], late: [sid], unmarked: [sid]}` from `getAssignmentStatus` + `assessmentCellValue(...).kind` ('none' = unmarked).
6. `classFeedbackCounts(cid, students, assessment)` → `{withComment: [sid], without: [sid]}` over scored students: a student "has feedback" when `getScoreComment(cid, sid, aid)` is non-empty or any of their entries on the assessment has `critNote`. (Do not count linked observations; `hasScoreOrFeedback` is close but counts scores — don't reuse it.)
7. `assessmentObservations(cid, assessment)` → `[{id, studentId, text, sentiment, date}]`, newest first, from `getAllQuickObs(cid)` filtered on `assignmentContext.assessmentId === a.id`.
8. `earlierInCategory(cid, assessment, n = 3)` → the `n` assessments in the same `categoryId` (or no category, when the assessment has none) with `_assessmentDate` before this one and the same scoring kind (points vs level vs complete), newest first, each with its `classColumnAverage`. Null when there are none. Format each figure with `classColumnAverageText`.
9. `otherClassesResults(cid, assessment)` → **async**: `findCopies(cid, a)` (it is in `teacher/assessment-copy.js`, a browser-global `AssessmentCopy.findCopies`; calc.js stays pure, so put this one function in a new `teacher/class-results.js`, not calc) → for each copy `loadClass(copy.cid).then(() => classColumnAverage(copy.cid, getStudents(copy.cid), {assessment: copyAssessment}))`. Returns `[{cid, className, text, pct}]` sorted by the class's `displayOrder`. Empty when the assessment has no `copyGroup`.
10. `pointsBands(cid, students, assessment, bandSize)` → bands of `bandSize` points (default `max/10` rounded to a whole number, min 1) with `{lo, hi, ids, byLevel: {1:[],…}}` using `pointsToProf(points, max, getGradingScale(cid))` for the level. Also return `levelRanges` (`{1: 'under 25', 2: '25–32', …}`) from the scale's boundaries so the Donut legend can show them.
11. `completionCounts(cid, students, assessment)` → `{complete: [sid], incomplete: [sid], unmarked: [sid], missing: [sid], excused: [sid], pct}` — `pct` as `getClassPointsAverage` computes it (Missing = 0, Excused out).
12. `dibelsClassResults(cid, students, assessment)` → `{periods: {boy|moy|eoy: {counts: {intensive,strategic,core,above}, ids, tested, medianWrc, medianAccuracy|null}}, latest, moved: {up: [sid], same: [sid], down: [sid]}}` from `getDibelsScore` + `dibelsLevel('orf', period, wrc)` + `dibelsAccuracy`. `moved` compares the latest tested period with the one before it. Skip NS/EXC students as `_dibelsCountsHtml` does.

Tests: `tests/class-results-calc.test.js`, seeded like `tests/gradebook-status-range-average.test.js` (fill `_cache.assessments/scores/statuses/rubrics/categories/observations`, `COURSES[CID]`, `clearProfCache()`): one Letter and one Proficiency fixture; cover NS/EXC rules in each, the Both class's figures, rubric grid counts, competency grid with a mixed criterion, feedback counts (overall vs criterion comment), earlier-in-category ordering and kind filter, points bands and level ranges, completion counts, DIBELS moved up/down and accuracy null when no errors. Add a test asserting the panel's median equals the ledger's for the same points seed.

## D. Other entry points (open the panel, never grading)

Rule: a place where the teacher expects a click to _grade_ or _edit_ keeps doing that (the Assignments card header, which expands the grading list; the Competencies-view column title and every student-page link, which open that card in Assignments; the questionnaire's Open in Grader; every phone row). A place that only _names_ the class's result, and today goes nowhere, opens Class Results. Every element that opens the panel carries `data-action="classResults" data-cid="…" data-aid="…"` and `title="View Class Results"`; one delegated click/keydown handler in `class-results.js` (registered once on `document`) opens it, so pages don't each wire it. The panel is page-agnostic: it lives in `#page-layout`, and `open(cid, aid, opts)` takes `opts.grade` (what Grade This Assessment does on that page) and `opts.onChange` (what to call after the panel changes data — the page's re-render).

1. **Gradebook, Scores view**: the Class Average cell (click, Enter, Space) and the column menu's **View Class Results** item (section C). `opts.grade` = `openGrader(firstRow.sid, aid)`; `opts.onChange` = `clearProfCache(); render()`.
2. **Gradebook, Competencies view**: the Class Average row's cells (the level and points cells in `renderDetailedTable` ~1612–1659 and `_pointsAverageCell`) get the same `data-aid`/`data-action` and the hover card. The group title keeps its Assignments link.
3. **Assignments page** (`teacher/page-assignments.js`): (a) in each card's header action group, beside the Edit pencil and Duplicate (`data-action="editAssess"` at ~1733), a **Class Results** button (icon: the same bar-chart SVG the Rubric score-mode card uses at ~3187, plus the text at the card's action size) — `data-action="classResults"`; (b) in an open card's points list, the `.ldg-stats` strip's leading `.ldg-name` "Class" becomes a link **Class Results** (`data-action="classResults"`), since that strip already shows Median / Lowest / Highest and goes nowhere; (c) the Complete/Incomplete tally (`.ldg-tally`) gets the same link at its end. `opts.grade` = `toggleAssess(aid)` when the card is collapsed, else focus the first row; `opts.onChange` = the page's render. Call `ClassResults.refresh()` wherever the page re-renders after a score, status or comment save (`refreshLedgerSummary`'s callers at ~2498, 6838, 7013, 7188 are the places; a single call at the end of the page's main render plus one after `refreshLedgerSummary` is enough).
4. **Not changed**, with the reason, so nobody re-litigates: the grader dialog's title (a modal; the panel would sit behind it); the Dashboard's Needs Attention "Missing: <title>" facts (a teacher reading a student's row expects a student action, and the row already has Gradebook →); the Core Competencies card's tips; observation cards' assessment chips (the click edits the observation); report blocks and print sheets; the phone app (no panel there in this PR).
5. **From the panel outward**: student names → `/student?course=<cid>&id=<sid>` (use the address the gradebook's name links use — grep `data-href="/student` in page-gradebook); class names under Other Classes → `/gradebook?course=<cid>`; Edit Assessment Details → `/assignments?course=<cid>&edit=<aid>`; See All under Observations → the Observations page filtered to the assessment if `page-observations.js` reads such a param (check `init(params)`), else the page unfiltered.
