## Steps

1. Choose **Create a Class**. If a class already exists, open **Class Settings** from the Dashboard and choose **New Class**.
2. **Choose Courses:** select a **Grade**, a **Subject** and one or more **Courses**, then choose **Next**. Selecting more than one course creates a combined class.

![The Choose Courses step with Grade 8, Science and Science 8 selected](img/create-a-class.jpg 'The Choose Courses step with Science 8 selected.')

3. **Choose Competencies:** all competencies are ticked. Untick any that will not be assessed in this class, then choose **Next**.
4. **Class Details:** the **Class Name** and **Grade Level** are filled in from the course. Change them if needed, set the **Grading System**, then choose **Next**. These can be changed later in Class Settings.
5. **Review:** confirm the details, then choose **Create Class**. The **Reporting Terms** shown here can be changed later on the Reporting Terms tab.

The new class opens on its **Students** tab. See [Add Your Students](add-your-students).
