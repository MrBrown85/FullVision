## Nov 11, 2026: Import Roster

A new class's Students tab now shows **Add Your Students**: drop a class list there or choose **Choose File**, with MyEd's three steps beside it. A MyEd class list goes straight to Ready to Add with nothing to match. Any other file opens **Check How Your File Was Read**, with each column's choice above its first rows and the guesses marked **Best Guess**. Birthdays like 5/22/2012 are read the way the column shows them. A date that isn't real, a student number used twice or a row with no name is listed on its row, and never stops the import. Afterwards a panel says what was added, and **Undo This Import** takes the new students back out.

## Nov 6, 2026: Download All My Data

**Download All My Data** in the account menu saves one Excel file with every class: a Summary, a gradebook sheet per class, and sheets for rubric levels, feedback, observations, reports, questionnaires and goals.

## Nov 6, 2026: Class Results

Hover over a Class Average in the Gradebook to see the spread of the class's results. Select it, or choose **View Class Results** in the column's menu, to open **Class Results**: the results by level, criterion and competency, who is below Proficient or Missing, feedback and observations on the work, and the same assessment in your other classes. Each assessment on the Assignments page has a **Class Results** button too.

## Nov 5, 2026: Dashboard Cards

Each student card's strip is now one labelled chip per folder, coloured by the student's level; point at a chip for its full name and level. The trend arrow sits beside the grade, and "N not assessed" appears only when a competency has no scored work yet. The Curricular Competencies card has a view menu beside its title: **Class Average**, **Level Mix**, **Needs Support** and **Change**. Click a competency to sort the class by it, weakest first, with a chip above the cards to clear it, a button to record an observation for the students below, and a link into the gradebook. The Core Competencies card shows students' **Self-Assessment** this term, or the **Evidence** tagged with each. On the student page, click the email address to copy it.

## Nov 5, 2026: Class Settings

The Class Management button on the Dashboard is now **Class Settings**. It opens the same screen, with the same tabs.

## Nov 5, 2026: Help Button and Keyboard Shortcuts

A **Help** button at the top right opens a panel beside the page. It lists the help pages for that page and for Getting Started, searches them, and shows a page in the panel; **Open in Help Site** opens it in full. **Keyboard Shortcuts**, in the panel or with the ? key, lists the app's keyboard shortcuts. On a phone, Help is in the Settings sheet.

## Nov 5, 2026: Roster Import and Codes

**Import Roster** first lists the columns a roster file can hold, with **Download Template** and **Choose File**. Hovering over a code beside a student's name, such as IE, shows what it means. Screens that called a competency a standard or a tag now say competency.

## Nov 5, 2026: Demo Mode Label

In Demo Mode, a **Demo Mode** label sits at the left of the top bar. Its menu offers **Create an Account**, **Sign In** and **Reset Demo Data**.

## Nov 5, 2026: Help Pages

Help pages at fullvision.ca/help explain each task step by step, starting with [Getting Started](/help). Each page quotes the app's own button and field names, and each task page shows a picture from Demo Mode.

## Nov 5, 2026: Setting Up a First Class

With no classes yet, Class Settings shows two cards: **Create a Class** and **Try Demo Mode**. **Open Demo Mode** asks before it replaces the data on the device. A new class opens on its **Students** tab, and **Save and Add Another** keeps the Add Student form open for the next student. In the New Class wizard, **Next** stays in place when a course is ticked, and the class cannot be created without a **Class Name**.

## Nov 5, 2026: Sensitive Health Topics in Report Comments

**Generate Comment** no longer writes about sensitive health topics, such as puberty, identity, bullying, substance use and mental well-being, and gives them no line for home. Their sentences can still be chosen from **Browse Sentences**.
